- Playwright 브라우저 설치: Chromium, Firefox, Edge (msedge는 시스템 브라우저 활용)

### 주요 파일
- `conftest.py`: pytest-playwright 내장 픽스처 활용 (browser/context/page/--browser/--headed 재정의 안 함)
- `pages/base_page.py`: click/fill/expect 래퍼 + 로거
- `pyproject.toml`: Ruff 설정
- `pytest.ini`: markers (ui/api/smoke/regression)
- `.github/workflows/ci.yml`: Lint → 3브라우저 병렬 테스트 매트릭스

## 배운 것 / 메모

- pytest-playwright는 `--browser`, `--headed`, `--browser-channel` 옵션을 내장 제공
  → conftest.py에서 이 옵션들을 재정의하면 충돌 발생 (argparse conflict)
- Edge 실행 방법: `--browser chromium --browser-channel msedge`
- Playwright에서 동적 렌더링 페이지는 `expect(locator).to_be_visible()`로 대기해야 함
  (`is_visible()`은 즉시 반환, 대기 없음)
